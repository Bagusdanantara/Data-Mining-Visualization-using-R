# Data-Mining-Visualization-using-R
Proyek ini merupakan analisis mendalam mengenai data Indeks Kelaparan Global (GHI) yang bertujuan untuk memahami tren serta hubungan antara berbagai indikator kelaparan di seluruh dunia. Fokus utama dari analisis ini adalah keterkaitan skor GHI dengan isu malnutrisi pada anak-anak, seperti stunting, wasting, dan underweight. Melalui serangkaian visualisasi data yang interaktif, proyek ini menyajikan perbandingan tingkat kelaparan antar negara dan benua, serta menunjukkan bagaimana tren ini berkembang dari waktu ke waktu.

Analisis ini didasarkan pada beberapa dataset dari Our World in Data, yang mencakup skor Indeks Kelaparan Global (GHI) sebagai metrik utama, serta data pendukung mengenai persentase anak kurang gizi (underweight), stunting, dan wasting.

Seluruh proses analisis dan visualisasi data dikerjakan menggunakan bahasa pemrograman R di dalam lingkungan R Markdown. Beberapa pustaka utama yang digunakan meliputi dplyr untuk manipulasi data, ggplot2 untuk membuat plot statis, serta plotly dan leaflet untuk membangun visualisasi yang interaktif dan mudah dipahami.
